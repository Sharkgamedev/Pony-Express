# The Pony Express
The Pony Express is a *just-for-fun* semi-serious side-project blog site about the daily lives of the Horses living on **Pony Planet**. It aims to adhere to the following values:
- Ship no JS by default
- Be simple, and load fast
- Support mobile devices well
  
  
Is blogging a solved solution? **Yes.**  
Are there already a million pieces of software such as []wordpress](wordpress.com), [ghost](ghost.org), etc. that solve this? **Absolutely.**  
Did I write this website in an incredibly inefficient manner, which makes it a pain to add more content too? **Also yes.**  
But I don't mind, because none of those things are the goal of this project, rather this is just a project for fun and to try my hand at different layouts and mobile responsiveness. That's all! (Also, who are you *really* if you don't have an 'over-engineered' hand-crafted blogging site?)  
Also I just really love Svelte. It's just that great.  
Regardless, go [check it out]](news.owensilva.net) if you want to learn more on what this is about.
